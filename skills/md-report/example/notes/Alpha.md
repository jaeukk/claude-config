# Alpha

Stealthy patterns have **no scattering** for probes with $2k\le K$ [[leseur_highdensity_2016]].
The window closes once the sample is too thick: $L/\ell_s^0\ll k_r\ell_s^0$.
In 2D the localization length grows as $\xi\sim\ell_t\,e^{\pi^2\ell_t/\lambda_e}$, so factor-2 changes of $\ell_t$ move $\xi$ by orders of magnitude.

| System | Gap width (%) |
| --- | --- |
| 2D rods | 45 |
| 1D chain | 21.65 |
| 3D network | 14 |
| Phononic | 60 |

Reported χ values: transparency at 0.15, 0.25 and 0.40; a 3D window at 0.20–0.35; a gap onset at χ ≳ 0.35.
